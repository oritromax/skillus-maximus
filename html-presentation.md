# HTML Presentation Builder

Build single-file HTML slide decks for technical/engineering presentations. Dark theme, animated entrances, keyboard + touch + dot navigation.

## Design System (Linear-inspired)

### Colors
```css
--bg: #08090a;           /* page background */
--bg-panel: #0f1011;     /* panel/surface bg */
```

### Typography
- Font: Inter (300/400/500 weights)
- Mono: JetBrains Mono (for code)
- Headings: weight 500, tight letter-spacing (-0.02 to -0.03em)
- Use `clamp()` for responsive font sizing

## Slide Structure

```html
<div class="slides-wrapper" id="slides">
  <div class="slide" data-index="0">
    <div class="slide-inner">
      <!-- animated elements use .anim-up, .anim-up-1..8 for staggered timing -->
      <h1 class="anim-up anim-up-1">Title</h1>
      <p class="subtitle anim-up anim-up-2">Subtitle</p>
    </div>
  </div>
</div>
```

### Scaled Content (2K+ monitors)
Use `transform: scale(1.3)` on `.slides-wrapper` with `transform-origin: center center` for 30% size increase. This keeps nav elements outside the scaled area at normal size. Never use CSS `zoom` — it clips right side when paired with `overflow: hidden`.

## Animation System

```css
@keyframes fadeUp {
  from { opacity: 0; transform: translateY(16px); }
  to   { opacity: 1; transform: translateY(0); }
}

.slide.active .anim-up { animation: fadeUp 0.5s ease both; }
.slide.active .anim-up-1 { animation-delay: 0.08s; }
.slide.active .anim-up-2 { animation-delay: 0.16s; }
/* ... up to anim-up-8 */
```

Slide transitions: opacity + translateY. Active slide at z-index 2.

## Navigation

Always include three navigation methods:

### 1. Dot indicators (right side)
```html
<div class="nav-dots" id="navDots"></div>
```
Generated by JS: loop over slide count, create buttons, add click handlers.

### 2. Arrow buttons (bottom center)
```html
<div class="nav-arrows">
  <button id="prevArrow" disabled>←</button>
  <button id="nextArrow">→</button>
</div>
```

### 3. Keyboard
- ArrowRight / ArrowDown / Space → next
- ArrowLeft / ArrowUp → prev
- Home → first slide
- End → last slide

### 4. Touch swipe
Track touchstart/touchend X delta, threshold 50px.

### 5. Mouse wheel
Debounced at 600ms to prevent rapid-fire.

## Component Patterns

### Rule Cards (grid)
2-column grid of numbered cards. Each has a number badge + text.

### Hierarchy Tree
Vertical ladder with colored labels. Each level gets a distinct color (indigo → blue → green → amber).

### Status Flow
Horizontal pill-shaped steps with arrow connectors between them. Use `flex-wrap: wrap` for overflow.

### Example Cards
Left-bordered cards. Story cards get green border, subtask cards amber, bug cards red. Subtask cards indented (margin-left).

### Bug Flow
Gate → Dev → Validation. QA Validation is a gate step (red, no SP).

### Capacity Bar
Flex segments with proportional widths. Dev work (SP) gets accent color, planning gets amber, buffer gets dashed border.

## Slide Counter

```html
<div class="slide-counter" id="slideCounter">1 / N</div>
```
Positioned `fixed; bottom: 32px; right: 32px`. Uses tabular-nums for alignment.
